# Temitope Seidu — Portfolio

This repo contains a single-file portfolio site (`index.html`) and the resume PDF (`resume.pdf`).

## Deploy
1. Upload files to a GitHub repo.
2. Enable Pages in repository settings (branch: `main`, folder: `/`).
3. Wait a moment and open the published URL.

## Edit
- Update `index.html` to change content, projects or links.
- Replace `resume.pdf` with an updated copy.
